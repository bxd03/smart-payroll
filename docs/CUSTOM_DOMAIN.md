# Free SmartPayroll address

The published app uses https://smartpayroll.greyapex8.chatgpt.site.

The site label was changed to `smartpayroll` at the owner’s request. This remains a free subdomain of the current hosting provider. No domain purchase is required.

`SmartPayroll.com` is not owned by the app owner and is not configured for use.

The same hosted application, database and account permissions are retained. Guest cookies are browser- and hostname-specific; changing the address does not transfer a guest cookie. Sign in with the same account to access account-owned data. The superadmin can still inspect guest workspaces through workspace administration.

Install the PWA from the new address. An existing home-screen shortcut may still point to the earlier address.
