# Acceptance checklist

- [x] Multiple companies and warehouse/property CRUD (archive instead of deleting referenced master records)
- [x] Worker names, IDs, rates, assignments and payment details
- [x] Excel/XLS/CSV, PDF text, image and scanned-PDF extraction
- [x] Editable and validated import review; original file downloads
- [x] Company-specific shifts and overnight working times
- [x] Per-company tolerance, rounding and overtime configuration
- [x] Exact five-minute example behavior, original record retention
- [x] Regular wages, overtime, allowances, deductions and net pay
- [x] Missing punches, unusual hours, duplicate and missing-record checks
- [x] Staff review, adjustments, finalization and locked records
- [x] XLSX reports and individual PDF payslips
- [x] History by company, worker and month; explicit payment records
- [x] Private hosted access, server validation, conflict protection and audit trail
- [x] Responsive navigation, labelled forms, keyboard-accessible dialogs

Statutory rates are not automatic. OCR rows must be reviewed. No bank transfers are performed.
